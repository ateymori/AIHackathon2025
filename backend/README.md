## Setup

Create a virtual environment and install the dependencies.

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
Copy the `.env.example` file to `.env` and add the necessary environment variables.

```bash
cp .env.example .env
```

Run the agent.

```bash
adk web
```
